# RSA를 직접 만들고, 부수고, 증명하기

PQC(양자내성암호) 커리큘럼 1단계(정수론) 실습.
파이썬 내장 암호 라이브러리 없이, 정수론 함수부터 직접 구현해 RSA를 완성했다.

> ⚠️ 학습용 장난감 구현이다. 작은 소수와 패딩 없는 교과서 RSA라서 실제 데이터 암호화에 쓰면 안 된다.


## 한 문장 요약

두 소수를 곱하긴 쉽지만 다시 쪼개긴 어렵다는 사실 위에, 서로소·모듈러 역원·오일러 정리를 쌓아
"공개키로 잠그고 개인키로만 여는" 자물쇠를 만들고, 부숴보고, 왜 동작하는지 증명했다.

도구 만들기 (step1 → step2 → step3) → 조립 (step4) → 공격 (step5) → 증명 (step6) → 실험 (step7 → step8)

## 파일 구성

| 파일 | 역할 | 핵심 |
|---|---|---|
| `rsa_step1.py` | 최대공약수 (유클리드 호제법) | 나눈 수는 앞으로, 나머지는 뒤로. 결과가 1이면 서로소 |
| `rsa_step2.py` | 모듈러 거듭제곱 (제곱-곱셈) | 지수를 2진수로 읽어 1인 자리만 곱하고, 곱할 때마다 mod |
| `rsa_step3.py` | 모듈러 역원 (확장 유클리드) | gcd 계산 옆에 "e를 몇 개 썼는지" 기록을 함께 계산 |
| `rsa_step4.py` | RSA 완성 | 키 생성 → 암호화 → 복호화 |
| `rsa_step5_attack.py` | 공격자 시점 | n을 소인수분해하면 phi, d가 줄줄이 나온다 |
| `rsa_step6.py` | 동작 원리 증명 | phi 묶음은 1로 사라지고 "+1"이 원문을 남긴다 |
| `rsa_step7_timing.py` | 공격 시간 측정 | n이 2자리 커질 때마다 공격 시간이 약 10배 늘어나는 법칙 발견 |
| `rsa_step8_predict.py` | 예측 검증 | 7단계 법칙으로 18자리 공격 시간을 미리 예측하고 실제와 비교 |


step1~3은 직접 실행하면 과정을 추적 출력하고, 다른 파일에서 import하면 함수만 제공한다
(`if __name__ == "__main__":` 사용).

## 실행 결과 예시 (step4)

```
n = 61 × 53 = 3233, phi = 3120
공개키 (e, n) = (17, 3233) / 개인키 (d, n) = (2753, 3233)
암호화: 65^17 mod 3233 = 2790
복호화: 2790^2753 mod 3233 = 65
```

## 공격 결과 (step5)

공개키 (17, 3233)만으로 시도 나눗셈 52번 만에 3233 = 53 × 61을 찾아 개인키 2753을 복원했다.
실제 RSA의 n은 617자리라 이 방법으로는 불가능하지만, 양자컴퓨터의 쇼어 알고리즘은 이를 가능하게 만든다.
→ 소인수분해가 아닌 다른 수학 문제(격자 문제 등)에 기반한 PQC가 필요한 이유.

## 왜 복호화되는가 (step6)

초미니 RSA(n = 33, e = 3, d = 7)로 검증:

```
31^7 = (4^3)^7 = 4^21 = 4^(20×1 + 1) = (4^20)^1 × 4 = 1 × 4 = 4
```

- e × d = phi의 배수 + 1 (모듈러 역원의 정의)
- 오일러 정리: m이 n과 서로소면 m^phi mod n = 1 (서로소 묶음에 m을 곱하면 순서만 섞이기 때문)
- 따라서 phi 묶음은 모두 1이 되고 m 하나만 남는다
- e × d = d × e 이므로 개인키로 잠그고 공개키로 열어도 된다 → 전자서명의 원리
- 안전성은 오직 n의 소인수분해가 어렵다는 것 하나에 달려 있다

## 공격 시간 실험 (step7, step8)

시도 나눗셈 공격으로 n의 자릿수를 2자리씩 키워가며 시간을 측정했다.

| n 자릿수 | 시도 횟수 | 시간 |
|---|---|---|
| 12자리 | 약 30만 번 | 약 0.03초 |
| 14자리 | 약 300만 번 | 약 0.3초 |
| 16자리 | 약 3천만 번 | 약 4초 |
| 18자리 | 약 3억 번 | 약 42초 |

- 관찰: n이 2자리 커지면 √n이 10배 커지므로, 시도 횟수와 시간도 약 10배씩 늘어난다
- 예측: 16자리 결과로 18자리를 약 40초로 예측 → 실제 41.6초 (배율 9.7배)
- 추정: 같은 속도로 617자리(RSA-2048)를 공격하면 약 10^293년 (우주 나이의 10^283배)
- 결론: 컴퓨터가 빨라지는 건 "곱하기"지만 문제가 어려워지는 건 "자릿수만큼의 거듭제곱"이라 따라잡을 수 없다.
  이 구조를 무너뜨리는 건 계산 방식 자체가 다른 양자컴퓨터(쇼어 알고리즘)뿐이다
